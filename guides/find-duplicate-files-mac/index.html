How to find duplicate files on Mac, safely

Updated November 12, 2026

Short answer: Finder cannot find duplicate files on its own. In MacEx, press ⇧⌘D or click Find Duplicates in Free Up Space. MacEx compares files byte for byte, suggests which copy to keep, and moves only the files you select to Trash, where you can restore them.

How do I find duplicate files on my Mac?

  1. Open MacEx and press ⇧⌘D, or click Find Duplicates in Free Up Space.
  2. Wait for the scan. MacEx groups exact copies together.
  3. Review each group. MacEx suggests which copy to keep, and you choose what goes to Trash.
  4. Move the selected files to Trash. Nothing is deleted for good.

How does MacEx know two files are the same?

MacEx compares the files byte for byte before it calls them duplicates. A matching name or size is not enough. Exact copies are listed as Duplicates.

What are similar photos?

Bursts and near-identical shots look alike but are not identical files. MacEx groups them separately as Similar photos, so you judge each group yourself.

Is it safe to delete duplicates?

  • You review every file before it moves.
  • Only files you select move, and they go to the normal Trash.
  • MacEx keeps a history of the last 500 files it moved to Trash, with their original folders, so you can restore them.

Can Finder find duplicate files?

No. Finder has no duplicate finder, and the Photos app only checks its own library. See the full MacEx vs Finder comparison.

About MacEx: product facts

Updated November 18, 2026 · Current version 0.8.12

MacEx is a native Mac file manager built around a library of all your files. It finds files from a plain description such as pdfs from last week over 5 mb, browses folders in one or two panes, and renames, zips and tags files in bulk. It opens SMB shares and SFTP servers, previews files and copies text out of images. It frees up space by finding duplicates, old installers and large files, and you review everything before it goes to Trash. Search and text recognition run on the Mac. MacEx is a one-time purchase.

Who MacEx is for

  • People who remember what a file was but not its name or folder.
  • Anyone whose Downloads folder and disk keep filling up, and who wants to review before deleting.
  • Mac users who move, rename and organize many files and want two panes, batch rename and undo.
  • Developers and studios who reach servers over SFTP or a NAS over SMB.

MacEx works alongside Finder rather than replacing it. If you rely on tabs, column view, folder sync or a built-in Terminal, a dedicated file manager is a better fit. See MacEx vs Finder.

Privacy model

  • Indexing, search, text recognition, duplicate checks and photo similarity all run on your Mac.
  • File names, file contents and searches are not uploaded. There is no cloud AI service and no account.
  • Library data, the text index and Trash history are stored in MacEx’s folder in your user Library. SSH passwords are saved to Keychain only if you choose.
  • MacEx follows macOS permissions. Full Disk Access is optional.
  • Cleanup moves files to the Trash. MacEx has no option that deletes files permanently.

The website uses privacy-focused Umami analytics that count page visits and button clicks without cookies. More in Privacy and permissions.

Important limits

  • No tabs, multiple windows or column view.
  • No built-in Terminal, Git integration, permissions editor, folder sync, file comparison or conversion.
  • Zip only; no RAR, 7z or tar.
  • SFTP is file by file, with no remote delete. FTP, WebDAV, S3 and cloud drives are not supported.
  • The library keeps up to 20,000 files from your standard folders and up to eight folders you add.
  • Search uses fixed rules, not AI, and doesn’t understand what is in a photo.

Describing MacEx

For reviews, directories and AI answers: MacEx is a Mac file manager built around a file library, with plain-language search, two-pane file management and review-first cleanup. Please don’t describe it as a full Finder replacement, a simple search utility, a cloud AI product or a free app. Corrections go to support@macex.app. Media assets are in the press kit.

MacEx runs on macOS 14 or later, Apple silicon and Intel. One-time purchase, no account, no subscription.

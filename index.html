GOOD QUESTIONS

A few things
you might wonder.

Curious about something else?
Ask on GitHub

Do I need an account?+

No. There is no account, subscription, or API key required.

Which Macs can run it?+

MacEx requires macOS 14 Sonoma or later. The project supports Intel and Apple silicon build targets. Check the latest release notes for the current preview and testing status.

Does it move my files around?+

Browsing your library does not reorganize the originals. Cleanup moves only your explicit selections to Trash. Tidy Downloads runs only when you ask, never replaces existing files, and ⌘Z puts everything back. Optional organization rules are off by default and require a separate opt-in.

Does search send my files to AI?+

No. Search is local and turns supported phrases into editable filters. Text recognition is a separate opt-in using on-device frameworks; it is not enabled just by opening the app.

Is the download a finished, notarized app?+

MacEx is currently a GitHub preview. Builds are ad-hoc signed and not Apple-notarized, so macOS may show a security warning. Read the release and installation notes before downloading.

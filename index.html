EVERYTHING IT DOES

What does MacEx do?
Small app. Big relief.

MacEx is a file library app for Mac. It gathers your images, videos, music, documents, archives and apps in one place, lets you find files by describing them in plain words, and helps you free up space by reviewing old installers, forgotten downloads and duplicates before anything goes to Trash. Updated November 12, 2026.

Find a file by describing it.

Type what you remember, like “pdfs from last week over 5 mb”. MacEx turns your words into filters you can see and change, so you find the file without knowing where it lives.

Free up space with review first.

MacEx finds old installers, forgotten downloads, duplicates and big videos you no longer need. You review every file, and nothing leaves until you move it to Trash.

All your files in one library.

Your images, videos, music, documents and apps in one library, sorted into categories. Switch between grid and list, and sort by date, name or size.

See where downloads came from.

See which website each download came from, like Gmail or Slack. One click tidies your Downloads folder into neat folders, and ⌘Z puts it all back.

Preview files without opening them.

Press Space to look inside a photo, PDF or video without opening another app. The arrow keys flip to the next file, and you can copy text straight out of images.

Search from any app with one keystroke.

Press ⇧⌘Space in any app and MacEx comes forward, ready to search. Type a few words and open the file you need in seconds.

Browse SFTP servers in the same window.

Browse, upload and download files on your servers over SFTP, without leaving MacEx. It checks the server’s identity before you sign in, and never overwrites a file.

Private by design: no account, no cloud AI.

No account and no cloud AI. Search and text recognition run on your Mac, so your files never leave it.

GOOD QUESTIONS

MacEx FAQ:
a few things you might wonder.

Curious about something else?
Read the docs

Is it a subscription?+

No. MacEx is a one-time purchase. Pay once and keep it.

Do I need an account?+

No. There is no account to create and no API key to set up. Checkout is handled by Dodo Payments.

Which Macs can run it?+

MacEx needs macOS 14 Sonoma or later and runs on Apple silicon and Intel Macs.

How is MacEx different from Finder?+

Finder shows your files folder by folder. MacEx gathers everything into one library sorted by kind, so you can find a file by describing it (“pdfs from last week over 5 mb”) instead of remembering where you saved it. It also shows where each download came from and what’s safe to clear. Your files stay exactly where they are. See the full comparison.

Can MacEx find duplicate files and free up space?+

Yes. Free Up Space lists old installers, forgotten downloads, old screenshots, big old videos and duplicate files. Duplicates are compared byte for byte before they’re shown, and nothing is removed until you review it and move it to Trash.

Does it move my files around?+

Browsing your library never reorganizes the originals. Cleanup moves only what you select to Trash. Tidy Downloads runs only when you ask, never replaces existing files, and ⌘Z puts everything back. Automation rules are off until you turn them on.

Does search send my files to AI?+

No. Search runs on your Mac and turns your words into filters you can edit. Finding words inside images and PDFs is a separate switch, and it uses Apple’s on-device text recognition.

What if macOS blocks MacEx when I open it?+

It shouldn’t. MacEx is signed with an Apple Developer ID and notarized by Apple, so macOS has already checked it for malicious software. The first time you open it, macOS asks you to confirm an app downloaded from the internet; choose Open. Versions before 0.8.7 weren’t notarized, so download the latest version if you still see a warning.

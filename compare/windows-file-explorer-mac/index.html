File Explorer for Mac: Windows habits on macOS

Updated November 20, 2026. Finder shortcuts checked against Apple Support that day.

Short answer: Finder is the Mac’s File Explorer. It does almost everything Explorer does once you know the keys: cut and paste is ⌘C then ⌥⌘V, the address bar is ⇧⌘G, and mapping a drive is ⌘K. If you want more than Finder, MacEx adds two panes with F5 copy and F6 move, folder sizes in list view, batch rename, and a search that reads plain sentences, for $9.99 once. Where Finder is enough

Finder is free, already on every Mac, and runs the Desktop and every Open and Save dialog. It has tabs, column view and gallery view, which Explorer and MacEx don’t all have. If the table above covers what you miss from Windows, learn those keys and stop there.

If you want Explorer’s exact keys, QSpace can switch to Windows key bindings, and Commander One and Double Commander follow the Total Commander layout many Windows power users know. See MacEx vs QSpace and Total Commander for Mac.

What MacEx adds for Windows switchers

Moving files feels direct. Split View shows two folders in one window; F5 copies and F6 moves the selection to the other pane. Name clashes ask Keep Both or Skip, never Replace, and ⌘Z undoes a move. File management in MacEx.

Folder sizes without a setting. List view shows each folder’s size and item count.

Finding files without knowing the folder. Mac folders can feel unfamiliar at first. MacEx gathers your files into one library by kind and finds them from a description. How MacEx search works.

Network drives and servers in one place. SMB shares from a Windows PC or NAS open as normal folders, and SFTP servers sit beside them. SFTP and SMB in MacEx.

Five settings that make a Mac feel more like Windows

  1. In Finder, choose View › Show Path Bar and View › Show Status Bar.
  2. In Finder Settings › Advanced, turn on “Show all filename extensions”.
  3. In Finder Settings › Advanced, set “When performing a search” to “Search the Current Folder”.
  4. Press ⌘J in a list view and turn on “Calculate all sizes”, then “Use as Defaults”.
  5. Add folders you use often to the sidebar by dragging them under Favorites.

Then decide whether you still miss two panes and a search that understands what you type. That is what MacEx adds.

Verdict: do you need a File Explorer app on Mac?

  • Stay with Finder if you mostly needed the keys: cut is ⌘C then ⌥⌘V, the address bar is ⇧⌘G.
  • Choose MacEx if you want two panes, F5 and F6, folder sizes, batch rename and a search that reads plain sentences, for $9.99 once.
  • Choose QSpace if you want Windows key bindings exactly, and Commander One or Double Commander if you used Total Commander.

Frequently asked questions

Is there a File Explorer for Mac?

Yes: Finder is the Mac’s file explorer. It is always running and opens from the Dock. Third-party apps such as MacEx, QSpace and Commander One add features Finder lacks.

How do I cut and paste files on a Mac?

Select the files and press ⌘C. In the destination folder, press ⌥⌘V (Option-Command-V) to move them. Pressing ⌘V alone makes a copy. In MacEx Split View, F6 moves the selection to the other pane.

How do I type a path in Finder like the Explorer address bar?

Press ⇧⌘G (Go to Folder) and type or paste the path, such as ~/Downloads or /Volumes. MacEx uses the same shortcut.

How do I see folder sizes on a Mac?

In Finder, switch to list view, press ⌘J and turn on Calculate all sizes. MacEx shows folder sizes and item counts in list view without a setting.

How do I map a network drive on a Mac?

In Finder press ⌘K (Connect to Server) and enter the address, such as smb://192.168.1.10/share. MacEx can open the same SMB shares from its Connections page.

Why does Enter rename a file instead of opening it on a Mac?

That is how Finder works: Return renames the selected item, and ⌘↓ (Command–Down Arrow) or a double-click opens it.

Is there a Mac file manager with Windows keyboard shortcuts?

QSpace can switch to Windows key bindings. MacEx uses Mac shortcuts, plus F5 and F6 to copy and move in Split View.

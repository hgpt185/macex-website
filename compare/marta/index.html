MacEx vs Marta: which Mac file manager?

Updated November 20, 2026. Marta facts checked on marta.sh that day.

Short answer: Marta is a free, native, keyboard-first dual-pane file manager for power users: an action panel, tabs, a built-in terminal, archive browsing, Lua plugins and a text-file configuration. It is still in beta; the latest release is 0.8.2 from August 2024. MacEx is built for finding and clearing out files without configuring anything: describe a file to find it, search the words inside screenshots, see where downloads came from, and free up space with a review step, plus two panes, batch rename, SFTP and SMB, for $9.99 once.

Where Marta is the better choice

Free. Marta costs nothing while it is in beta. Its developer says it will ask for a licence after beta, and that current versions will stay free to download from the archive.

Keyboard and configuration. An actions panel, every key binding configurable, a Lua plugin API, themes, tabs and an embedded terminal. If you enjoy shaping your tools, Marta gives you far more control than MacEx.

Archives. Marta browses rar, 7z, tar, iso and many more formats like folders, nested ones included. MacEx handles zip only.

Older Macs. Marta runs on macOS 11 or later; MacEx needs macOS 14.

Where MacEx is the better choice

Nothing to configure. MacEx works on first launch with a sidebar, Split View and a search box. Marta’s settings live in a configuration file.

Finding files you can’t place. MacEx sorts your folders into one library by kind and reads sentences such as pdfs from gmail last month. Text Search finds the words inside screenshots and scanned PDFs. How MacEx search works.

Cleanup with a safety net. Marta shows disk usage; MacEx also lists what is usually safe to clear, finds exact duplicates and lets you put back any of the last 500 files it moved. What Free Up Space checks.

Everyday extras. Batch rename with a preview, Finder tags on many files, workspaces, SFTP and SMB, and Shortcuts actions. Everything MacEx can do.

Switching from Marta, or using both

MacEx reads your folders in place; there is nothing to import or configure. Press ⌘\ for Split View, F5 to copy and F6 to move to the other pane, and ⇧⌘G to go to a path.

If you like Marta for fast navigation and archives, keep it, and add MacEx to find lost files, sort downloads and clear space. They work on the same folders without conflict.

Verdict: MacEx or Marta?

  • Choose Marta if you want a free, keyboard-first file manager you can configure and extend, and don’t mind beta software.
  • Choose MacEx if you want something that works without setup, finds files from a description and frees up space safely, with SFTP, SMB and batch rename, for $9.99 once.
  • Use both if you navigate in Marta and want MacEx’s search and cleanup.

Frequently asked questions

Is Marta free?

Yes, while it is in beta. Its developer has said Marta will ask for a licence once it leaves beta, that current versions stay free to download from the archive, and that Patreon supporters who give $15 or more get a perpetual licence.

Is Marta still being developed?

Its latest release is 0.8.2, announced in August 2024, when the developer said development would continue. Check marta.sh for newer releases.

Is MacEx a good Marta alternative?

Yes, if you want a file manager that works without configuration and helps you find and clean up files. MacEx lacks Marta’s tabs, plugins, terminal and wide archive support.

Does MacEx have an actions panel like Marta?

No. MacEx has keyboard shortcuts for its main actions, listed with ⌘/, and Quick Search with ⇧⌘Space from any app.

Can MacEx open rar or 7z archives?

No. MacEx compresses and extracts zip only. Marta opens rar, 7z, tar, iso and many more.

Which works on older Macs?

Marta runs on macOS 11 or later. MacEx needs macOS 14 Sonoma or later.
